# covid19-pbmc-scrnaseq-seurat
Single-cell RNA-seq analysis of COVID-19 and healthy samples in R (Seurat)

Dataset

The dataset used in this project was obtained from the study:

A single-cell atlas of the peripheral immune response in patients with severe COVID-19

Published in Nature Medicine. (https://www.nature.com/articles/s41591-020-0944-y)

Samples Analyzed

A total of four samples were included in the analysis:

COVID-19 patients: Three infected samples (IDs: 556, 557, and 558).

Healthy control: One sample from a healthy individual.

The dataset was used to investigate and characterize the peripheral immune response associated with severe COVID-19 at the single-cell level.
